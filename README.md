# ChickenWing

ChickenWing aide les techniciens son à préparer leurs shows pour les consoles Behringer WING, Midas M32 et Yamaha QL, CL et DM.

- Importer un patch depuis une fiche technique au format PDF, image, Excel, ODS ou CSV.
- Préparer les entrées, les sorties, le routage et les effets, avec un catalogue de micros et de DI.
- Dessiner un plan de scène et générer une fiche technique A4 en PDF.
- Exporter des fichiers pour les consoles compatibles et adapter un show à une autre console avec Show Evangelist.
